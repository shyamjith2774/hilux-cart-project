Hilux Cart — E-Commerce Web App

A fully responsive and modern React + Tailwind e-commerce application with product listing, filtering, cart management, and dynamic UI updates. Designed with clean component architecture and smooth user experience.

🚀 Features
🛍 Product Display

Dynamic product listing

Category-based filtering

Search functionality

Product detail page with images & description

🛒 Shopping Cart

Add to Cart / Remove from Cart

Quantity update

Automatic total price calculation

Persistent cart using state 

🌐 Navigation

Smooth routing with React Router

Pages: Home, Products, Product Details, Cart,AboutUS and ContactUS

🎨 UI & UX

Fully responsive using Tailwind CSS

Modern card design

Clean layout with reusable components

📦 State Management

Context API

Cart logic handled globally for consistency

🛠 Tech Stack

React.js

Tailwind CSS

React Router

JavaScript (ES6+)
